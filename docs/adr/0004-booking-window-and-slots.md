# 0004. Окно бронирования и параметры слотов

**Статус:** принято

**Контекст:** гостю нужен предсказуемый набор доступных слотов: сколько дней вперёд можно записаться, в какие часы, с каким шагом и в каком часовом поясе считаются даты.

**Решение (зафиксированные параметры):**

- **Часовой пояс:** `Asia/Almaty` (UTC+5) — все даты и время в API в этом поясе.
- **Окно бронирования:** 14 календарных дней, начиная с завтрашнего (`завтра … завтра+13`), скользящее. Даты вне окна — `400`; «на сегодня» записаться нельзя.
- **Рабочие часы владельца:** пн–пт, 10:00–18:00; выходные недоступны.
- **Длительность слота:** равна длительности выбранного типа встречи.
- **Шаг стартов:** 30 минут независимо от длительности; последний старт — такой, чтобы встреча закончилась не позже 18:00.

**Последствия:** параметры пересматриваются только по явному запросу пользователя; слоты считает бэкенд (рабочие часы минус занятые бронирования), фронтенд их только отображает.

**Источники:** README «Доменные правила (зафиксированные параметры)»; спека #1 (Notes: окно 14 дней с завтрашнего, 10:00–18:00 пн–пт, шаг 30 — фиксированные входные данные карты).
