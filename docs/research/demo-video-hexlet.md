## Метод

Ссылка ведёт не на один файл, а на **публичный альбом** файлохостинга Hexlet files из **8 объектов**
(название альбома в метаданных: `ai development calendar slot project ru`):

- 1 видео: `RvcbWAc8JWe9.webm` — WebM/VP8, 1400×1050, 25 fps, **длительность 10.8 с** (~0.78 МБ), без звука;
- 7 PNG-скриншотов 1400×1050 — состояния тех же экранов.

Прямая ссылка на `files.hexlet.app/<file>` отдаёт 404; файлы доступны через CDN
(`https://cdn6.hexlet.io/<file>`). Кадры извлечены ffmpeg (бинарь из пакета `imageio[ffmpeg]`
в изолированном venv, ничего глобально не устанавливалось) с шагом 2 кадра/с — 22 кадра,
все ключевые кадры и все 7 скриншотов просмотрены и расшифрованы.

## Главный ответ

**Язык UI — русский: допущение карты подтверждено.** Все заголовки, кнопки, подписи и
сообщения на русском; нерусские только бренд «Calendar» и демо-данные гостей
(`Demo User 1774622525745`, `demo-1774622525745@example.com`).

Демо показывает **5 экранов**: главная страница, страница записи (календарь + слоты),
подтверждение записи (форма), экран успеха, список предстоящих событий.
Экранов заведения типов встреч и выбора типа встречи в демо **нет** — бронируется
единственный неявный «звонок» фиксированной длительности 30 минут.

## Общий каркас UI

- Шапка на всех экранах: слева логотип (оранжевая иконка календаря) + слово **«Calendar»**;
  справа две вкладки-навигации: **«Записаться»** и **«Предстоящие события»**.
  Активная вкладка подсвечена светло-серой «пилюлей», неактивная — просто текст.
- Контент по центру, максимальная ширина ~1120px; светлый фон, карточки белые с тонкой рамкой.
- Акцентный цвет — оранжевый (кнопки, выбранные дата/слот, рамка поля в фокусе).

## Экран 2. Страница записи (календарь + слоты)

(скриншоты `t5QPzSarFLUt.png`/`d92bKoYDj0ZP.png` — начальное состояние, `jWviXIUlXeYG.png` и
`esXHhgGyqbql.png` — с выбранной датой, `MkoSq9iBJaWV.png` — с выбранным слотом;

- H1: **«Запись на звонок»**
- Три колонки-карточки:

**Левая — «Информация»** (4 серых блока «подпись / значение»):
- «Выбранная дата» → «Дата не выбрана» | «суббота, 28 марта» (дата — строчными, с днём недели)
- «Выбранное время» → «Время не выбрано» | «09:30 - 10:00» (дефис с пробелами)
- «Свободно» → «0» | число свободных слотов в выбранный день (в демо: 18 → 17 → 16)
- «Длительности в дне» *(sic, так написано)* → «Нет слотов на этот день» | «30 мин»

**Средняя — «Календарь»:**
- Заголовок «Календарь», справа круглые кнопки «←» «→» (листание месяцев).
- Подзаголовок: «март 2026 г.» (месяц строчными + «г.»).
- Сетка недель **Пн–Вс** (неделя с понедельника), включая даты соседних месяцев.
- Недоступные даты — бледно-серые, без подписей (в демо: 23–27 марта при «сегодня» 27.03).
- Доступные даты содержат подпись-счётчик под числом: **«17 св.»**, **«18 св.»** (число
  свободных слотов; «18 св.» у всех полностью свободных дней — согласуется с 18 слотами
  по 30 мин между 09:00 и 18:00).
- Выбранная дата — белая с **оранжевой рамкой** («28 / 17 св.»).

**Правая — «Статус слотов»:**
- Пока дата не выбрана: серый плейсхолдер **«Выберите дату в календаре.»**
- После выбора даты — вертикальный список слотов-строк: слева интервал **«09:00 - 09:30»**,
  справа статус **«Свободно»** (жирным) или **«Занято»** (серым, строка приглушена).
  Видимы слоты с 09:00 по 12:30 включительно (7 строк) — дальше, судя по счётчикам, список
  продолжается до 18:00.
- Клик по свободному слоту выделяет строку **оранжевой заливкой**; в «Информации» появляется
  «Выбранное время».
- Внизу карточки две кнопки: **«Назад»** (белая) и **«Продолжить»** (оранжевая;
  пока слот не выбран — бледно-оранжевая, disabled).

## Хронология видео (10.8 с)

1. ~0 с — белый экран (загрузка).
2. ~0.5 с — главная страница.
3. ~1.5 с — «Запись на звонок»: дата **суббота, 28 марта** уже выбрана; слот
   «09:00 - 09:30» — «Занято», остальные свободны; «Свободно 17»; «Продолжить» disabled.
4. ~3.5 с — клик по «09:30 - 10:00»: строка оранжевая, «Выбранное время 09:30 - 10:00»,
   «Продолжить» активна.
5. ~5.5 с — «Подтверждение записи»: пустые «Имя»/«Email».
6. ~7 с — поля заполнены; клик «Подтвердить запись».
7. ~7.5 с — «Бронь подтверждена. До встречи!» + «Забронировать еще».
8. ~8 с — возврат на «Запись на звонок»: «09:30 - 10:00» теперь тоже «Занято»,
   «Свободно 16», у даты «16 св.» — **подтверждение конфликт-контроля и пересчёта слотов**.
9. ~9–10.8 с — вкладка «Предстоящие события» с двумя карточками (вторая — только что
   созданная бронь).

## Флоу гостя (реконструкция)

Главная → «Записаться» → страница записи → выбор даты в календаре → выбор свободного слота →
«Продолжить» → форма «Имя» + «Email» → «Подтвердить запись» → экран успеха →
«Забронировать еще» (повторный цикл) или вкладка «Предстоящие события».

## Флоу владельца

В демо отдельного флоу владельца **нет**: ни создания типов встреч, ни какой-либо
админ-вкладки. Просмотр «Предстоящих событий» доступен из общей шапки без авторизации.

## Что берём из демо в реализацию

1. Русский UI; тексты — дословно как выше («Запись на звонок», «Предстоящие события»,
   «Бронь подтверждена. До встречи!», «Забронировать еще», «Выберите дату в календаре.»,
   «Свободно»/«Занято», «Назад»/«Продолжить», «Изменить», «Подтвердить запись»).
2. Трёхколоночная страница записи: «Информация» | «Календарь» | «Статус слотов»; календарь
   Пн–Вс со счётчиками «N св.» у доступных дат; кнопки «Назад»/«Продолжить».
3. Шаг подтверждения с «Изменить» и полями «Имя»/«Email».
4. Экран успеха с кнопкой повторного бронирования.
5. «Предстоящие события» — карточки: имя (жирное), email, слот, дата создания.
6. Навигация-вкладки «Записаться» / «Предстоящие события» в шапке; бренд «Calendar».
