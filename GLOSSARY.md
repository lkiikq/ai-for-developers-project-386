# Календарь звонков

Сервис для бронирования времени звонков без регистрации: один предопределённый владелец календаря заводит типы встреч, гости записываются на свободные слоты.

## Language

**Главная страница**:
Страница, с которой начинается знакомство гостя с сервисом: описывает сервис и ведёт на страницу записи. Списка типов встреч на ней нет.
_Avoid_: лендинг, хоум

**Страница записи**:
Страница, на которой гость выбирает тип встречи, чтобы начать бронирование.
_Avoid_: страница бронирования
