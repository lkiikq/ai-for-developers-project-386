# Календарь звонков

Сервис для бронирования времени звонков без регистрации: один предопределённый владелец календаря заводит типы встреч, гости записываются на свободные слоты.

## Language

**Главная страница**:
Страница, с которой начинается знакомство гостя с сервисом: описывает сервис и ведёт на страницу записи. Списка типов встреч на ней нет.
_Avoid_: лендинг, хоум

**Страница записи**:
Страница, на которой гость выбирает тип встречи, чтобы начать бронирование.
_Avoid_: страница бронирования

**Страница слотов**:
Страница записи на конкретный тип встречи: выбор даты и слота, подтверждение и успех идут шагами внутри одной страницы. Несёт заголовок «Запись на звонок», как и страница записи, — вместе они образуют один флоу.
_Avoid_: страница календаря, страница бронирования

**Предстоящие события**:
Страница владельца со списком броней с сегодняшней даты включительно (Asia/Almaty), отсортированных по дате и времени встречи. Уже начавшиеся сегодня встречи входят в список.
_Avoid_: предстоящие встречи, расписание

**Тип встречи**:
Заданный владельцем шаблон встречи: название, необязательное описание и длительность (30, 60, 90 или 120 минут). Гость выбирает тип на странице записи.
_Avoid_: вид встречи, услуга

**Слот**:
Интервал времени конкретного дня, на который можно записаться: начало на получасовой сетке в рабочие часы, длительность равна длительности выбранного типа встречи.
_Avoid_: таймслот, окошко

**Бронь**:
Запись гостя на слот: занимает интервал целиком и для всех типов встреч.
_Avoid_: резервирование, запись (в значении сущности)

**Владелец календаря**:
Единственный предопределённый пользователь, который заводит типы встреч и смотрит предстоящие события. Авторизации нет, страницы владельца доступны всем.
_Avoid_: админ, хозяин календаря

**Гость**:
Пользователь без регистрации, который выбирает тип встречи и бронирует свободный слот.
_Avoid_: клиент, посетитель
